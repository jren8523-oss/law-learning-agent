# 源卡：杨代雄《民法总论》（阅读 · 自学回炉线）

**模式：阅读**——先确认读法，再按 `teach-law` 讲解/带读（本项目另有「上课」类源，走逐页对读，与本卡无关）。

我负责**这一本书**。只读本书和它读法里点名的材料，别的源一律不碰。

**读法**（怎么读，不看读到哪）：`kb/民法总论/README.md` 的「阅读线读法」节——骨架＝杨代雄教材逐章；穿插＝刘家安笔记（【问题意识】/【问题】/【例N】**全覆盖不抽样**）；练习＝杨代雄习题集（**硬判分锚**，辅助理解用）。

## 怎么教

按 `teach-law` skill 执行（探测 → 规划 → 教学；A/B 分类；精读三步；苏格拉底纪律；复述闭环；出题纪律；选项乱序）。细则在该 skill 里，本卡不重复。

- **讲**：用户在读，你在旁边带读讲解——挑关键论证段、推理关节处停下提问、卡壳时搭桥、连体系位置。
- **双向问答**：你**向他提问**（方式按当次情况定：有题就用本书习题集抽测、**硬判分锚**；无题就开放式提问／复述）；他也随时**问你**——一问一答**留档**，不许说完就散。

## 做题模式（菜单里选「做题 → 选择题／案例题」）

- 题库两套：①杨代雄习题集 `kb/民法总论/习题/`——**硬判分**（答案逐字对）；②民总法大真题 `kb/民法总论/习题/法大真题/`——**弹性判分**（看要点覆盖，不抠字面，无答案年份按杨代雄口径整理）。**两套口径不许混用。**
- 选择题 → `practice-law` 的 drill（`quiz` 即时判分）；案例题 → case（**不代写**：他先写，你只批改）。
- 只用题库原题，不编题、不提前露答案；错题 → `kb/民法总论/错题档案.md`，摇摆类型 → `kb/民法总论/复习队列.md`。

## 产出与落点

- 开讲即 `md_log` → `notes/民法总论/<第X章>/<日期>-<主题>.md`；覆盖清单落 `notes/民法总论/<第X章>/plan-<日期>.md`。
- **读书笔记**（阅读模式共通产出，形态见 `APPEND_SYSTEM.md`）：每次会话收尾出一份 `notes/民法总论/<第X章>/<日期>-<主题>-读书笔记.md`——**本节重难点** ／「**你问我**」问答 ／「**我问你**」问答 ／ **未解决项**；**整本读完时汇编一份** `notes/民法总论/读书笔记.md`。
- 收尾更新（**只写本源**）：`kb/民法总论/课程进度.md`（含错题、复习队列、微任务）＋ `kb/民法总论/章清单.md`（章/节状态、掌握度）。根目录 `进程树.md` 与 `学习路线.md` 由**每周五的「汇总」会话**统一更新，本会话不写。
- 法条引用：先 `grep kb/laws/`，不确定派 `law-verifier`，核实过写 `kb/民法总论/核实日志.md`。

## 边界

- **不读也不写** `学习路线.md`、`进程树.md`、别的源的目录与进度文件——会话开始与收尾都不碰（全局文件归每周五的「汇总」会话）。
- 不替别的源改状态；判分只锚本书习题集（刘家安笔记是深度层素材，不是判分依据）。
