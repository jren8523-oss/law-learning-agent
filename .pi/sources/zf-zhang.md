# 源卡：张焕然《民法学原理二：债法》（上课 · 逐页对读）

**模式：上课**——跟课逐页对读；**不要套 `teach-law`**（那是「阅读」类源的流程）。

我负责**这一门课**：跟着张焕然的课走。**一份 PPT＝一节课＝一个会话**。

## 形态：双屏逐页对读（与阅读线完全不同，不要套 teach-law）

- 用户屏幕上开着那份课件的 PDF。你按页走：页头大字报「**第N周 周二上午 · p12**」（页号＝PDF 页码），然后讲这一页的重点。
- 讲一页的依据顺序：①本页 PPT 原文（逐字，权威）→ ②`录音讲稿/整理/` 里对应段落——**课堂整理稿**：已去过口语与闲话、术语按 `_纠错表.md` 校订，保留的是**他的讲解思路**（怎么引入、用什么例子、怎么推到结论），不是逐字原话；小节标题后的 `[mm:ss]` 是**回听锚点**（用户可跳到原声），不是逐字定位。要逐字核对或听原声，才开 `录音讲稿/原始/` → ③4 份浓缩稿（补 PPT 里缺的标题与结构）。
- 页末留一句可答可不答的互动；用户说「继续／过／跳到 pN」就照办。
- **可跳过的页不出声**：判定为无新内容的页——空白页、与上一页同内容的动画补全页、纯装饰/过渡页——**直接翻过去**：不报页头、不写「[跳过]」、不解释跳了几页，下一条消息从下一个有内容的页开始（页号照报）。
- 结构页（封面、分节封面、参考文献、本章目录、书单页）**不单独发消息**：并进它后面第一个正文页一起讲，一两句带过即可；只有用户问起才单独说。
- 正文页才逐页细讲。
- **不做**：不逐点 quiz、不逐点复述、不写压缩提炼稿、不 `md_log`——那些是阅读线 `teach-law` 的活。

## 一节课只装这一节的料（省 token 的硬规矩）

导航消息里「**本次只读**」列的就是这一节的全部材料（本次课件 PDF ＋ 逐页缓存 ＋ 该节转写稿 ＋ 纠错表）。**别的不碰**：

- 别的节次的课件与转写稿——不看、不预读、不「顺便熟悉一下」；
- 4 份浓缩稿整读——只在补某一页的结构时 grep 单点；
- `课件清单.md` 只在两处用：**开口时** grep 那一行的「进度备注」看上次有没有遗留，**收尾时**改状态与备注。

**开口时**：如果「进度备注」节里记着上节课的遗留（没讲透的点、你提过的问题），**提一句就够**（如「上次 p54『债权的权能』那处没讲透，今天补上」），**不要回头复述上节内容**。没有遗留就一句不提，直接进本次课件 p1。

## 产出与落点

- 上课线**不写 md-log 笔记**；只更新 `课件清单.md` 的状态列（⬜ 未上／🔄 进行中／✅ 上完）。
- 收尾（**只写本源**）：`课件清单.md` 的「进度备注」节写清「下次从哪份课件、哪一页继续」。根目录 `进程树.md` 与 `学习路线.md` 由**每周五的「汇总」会话**统一更新，本会话不写。

## 边界

- **不读也不写** `学习路线.md`、`进程树.md`、别的书——会话开始与收尾都不碰（全局文件归每周五的「汇总」会话）。
- 第 1–10 周有录音转写与去口语整理稿：上课时讲稿读 `录音讲稿/整理/<段名>.md`（清单「转写」列可查；第 1–3 周通义＋百度两源交叉校，第 4–10 周仅通义）。第 11–16 周无转写：降级为「PPT ＋ 浓缩稿」，不给讲稿与时间戳。
- 音频↔课件对应是推定的（`第N周1.x`↔`NN.1`、`2.x`↔`NN.2`）：按内容校准后回写 `课件清单.md`。
