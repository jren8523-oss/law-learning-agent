# 源卡：总账 · 每周汇总（汇总 · 每周五）

**模式：汇总**——**不套 `teach-law`／`practice-law`**：这是「记总账」的会话，不是教学会话。

我负责**项目的总账**：把「这一周做了什么」记进根目录 `进程树.md` 的「周记」节（它就是 Obsidian 首页），用来督促自己。**一周一次（周五）**。平时教学/阅读会话只写本源自己的进度文件、不碰全局，所以这里要一次把全局补齐。

## 一、读什么

| 读什么 | 路径 |
|---|---|
| 总账（上周周记 + 各线一行） | `进程树.md` |
| 线路位置（周级快照） | `学习路线.md` §六 |
| 民法总论 · 阅读线 | `kb/民法总论/课程进度.md`、`错题档案.md`、`复习队列.md`、`章清单.md` |
| 债法 · 阅读线 | `kb/债法总论-解亘/课程进度.md`、`章清单.md` |
| 债法 · 上课线 | `kb/参考讲义/张焕然债法/课件清单.md`（**「进度备注」节**＋状态列） |
| 民法总论 · 上课线 | `kb/参考讲义/张焕然总论/课件清单.md`（「进度备注」节） |
| 合同法总论线 | `kb/合同法总论-韩世远/课程进度.md`、`章清单.md` |
| 债法校课 | `kb/债法/课程进度.md` |

| 笔记 | `notes/<书>/<分章目录>/` 里本周新增的 md |

导航消息里「**本会话要读**」已由代码把上面的路径列全（含各源卡的 `progress:`／`ledger:`），照它读即可。

**只看本周的增量**：各源进度文件里**上次周记之后**的新增记录（记录自带日期；上次记到哪天＝`进程树.md` 「周记」节最上面那一条的范围）。**还没有上一条周记时（第一次汇总）就看本周一至今**。没有新记录的线，写「本周未动」一行即可。**不许整读大文件**：教材、笔记正文不必读，进度文件用 `grep`／`Read` 取「最近记录」那几节。

## 二、数字一律数出来，不许手编

| 数字 | 数法 |
|---|---|
| 民法总论错题／复习队列 | `grep -c '^| 20' kb/民法总论/错题档案.md`、`…/复习队列.md` |
| 解亘错题／复习队列 | 同法数 `kb/债法总论-解亘/课程进度.md` 的两节（`^| 20` 开头的数据行） |
| 本周笔记篇数 | `ls notes/<书>/<分章目录>/` 里文件名以本周日期开头（`2026-10-1x`）的 md 数 |
| 本周会话次数／上到哪 | 各源进度文件「最近记录」里的日期条数；上课线看 `课件清单.md` 状态列与「进度备注」 |

数出来的数就是数；数不出来（某文件没有）就写「—」，不猜。

## 三、先报后写

先在对话里给**草稿**（不落盘），四块：

- **本周做了什么**：按线一行行——哪天、到哪一节／哪一页、什么结果（如「B2-b 讲完 N5–N7，N8 卡住」）
- **数字**：本周会话 N 次 · 新笔记 N 篇 · 错题 +N · 复习队列 N 项
- **卡点／没做完**：没交的微任务、卡住的节点、整周没动的线
- **下周**：大致打算（一句话就够，不必排课表）

末尾问一句「这样记可以吗／要改哪里」，**等用户点头或改过之后**再落盘。

## 四、写哪三处（只改这三处）

1. **`进程树.md` → 「周记」节顶部加一条**（本周条目已存在＝就地更新那条，不新建）：
   ```
   ### 2026-W42（10-12～10-18）
   - 做了什么：…
   - 数字：…
   - 卡点/没做完：…
   - 下周：…
   ```
   周号与日期范围**照导航消息里给的那串写**，不要自己算 ISO 周。
2. **`进程树.md` → 「各线一行」表、「待办」、「最近笔记」**按本周情况刷新（最近笔记＝`notes/` 里最新的 10 条链接）。表格单元格里的 wikilink 要写成 `[[路径\|显示名]]`（**转义竖线**），否则表格会断列。
3. **`学习路线.md`** → §六「最近完成／进行中／下一课」几行改成最新（**键名不许改**——各源卡的 `route:` 指着它们）；§四 教案表里已上完的课，把状态列改成 ✅（只改状态列，不重排课次、不改课名）。

## 五、边界

- 不碰各源的进度明细（`课程进度.md`／`章清单.md`／`课件清单.md`）与教学数据、题库——每条线的账由那条线自己记，本会话只**读**它们。
- 不评判学得怎么样、不补做教学、不派子代理、不建新目录、不写脚本。
- 想随时记一笔：菜单里选「汇总」，或敲 `/weekly`。
- 写完在对话里报一句「已记入 `进程树.md` 的 2026-W42」即可，不必长篇总结。
