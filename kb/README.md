# kb/ — 你的知识库

这里是你的学习材料。**本目录下的内容不进 Git**（只保留本说明文件），你自己往里填。

## 结构约定

一源一个子目录，目录名 ＝ 书名或课程名：

```
kb/
├── README.md              ← 本文件
├── 教材库.md               ← 书目登记表（有哪些书、什么角色、进度）
├── laws/                  ← 法条原文（供引用核对）
└── <书名>/
    ├── README.md           ← 本书材料索引：章 ↔ 页码映射、材料角色、读法
    ├── 课程进度.md          ← 讲到哪、上次遗留什么（会话开口先读这份）
    ├── 章清单.md            ← 章/节级状态与掌握度
    ├── 错题档案.md          ← 做错的题与记忆锚点
    ├── 复习队列.md          ← 待复习条目
    ├── 核实日志.md          ← 已核实过的法条/知识（避免重复核实）
    ├── 教材/                ← 逐章正文（NN-第X章.md）
    └── 习题/                ← 检测题库（题目/答案分离存放）
```

不是每本书都要建全——按你实际用到的建。开一本新书时，先定读法写进它的 `README.md`，再建进度文件。

## 材料从哪来

原始 PDF/PPTX 放 `material/`（不进 Git），用 `tools/` 里的脚本转成逐页/逐章 markdown 落到这里。转换与验收见 `tools/README.md`。

## 为什么这样分

- **源卡（`.pi/sources/<id>.md`）** 管「这门课/这本书怎么教、只准读哪些路径」；
- **kb/<书名>/README.md** 管「这本书的章↔页码、材料角色」；
- **进度三处归位**：怎么读 → `README.md`；读到哪 → `课程进度.md`；章级状态 → `章清单.md`。
