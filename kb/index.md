# 法条知识库索引

这是法学学习 agent 的本地法条知识库。agent 讲法条前先查这里；新知识按本规范入库。

## 格式规范

- 每部法律一个文件：`kb/laws/<规范简称>.md`
- 文件头部注明全称、效力状态与施行/修订日期
- 条文按「条」组织；款、项用缩进或（一）（二）序号保留原文结构
- 只收录**现行有效**文本；已废止/已修正的旧法在「沿革」一节简要注明，供对比学习

## 入库原则

1. 只录**核实过**的现行有效文本（来源：国家法律法规数据库 flk.npc.gov.cn）。
2. 节选优先收录「教学价值高」的条文：基本原则、高频考点、构成要件。
3. 入库时让 `law-verifier` 子代理复核一遍。
