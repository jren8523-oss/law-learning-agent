## 使用说明

- 教材文件按章存放；教学时先读章首「来源」标注的页码区间，可回溯原 PDF。
- 习题题目与答案分离：出 quiz 时只读「题目」文件，判分后核对「答案」文件。
- 习题文件由 `tools/normalize_exercises.py` 从 PDF 重建（去页眉页脚/水印杂字，拆开粘连的选项与题号）：
  - 题目文件：`## 大题` + `N. 题干` + 每行一个选项（`A.`…）；题干文字一字未改。
  - 答案文件：选择题是「`1. C` / `1. ABD`」逐条清单（按题号取行，**不要去数压缩串**），文字题在后。
  - 自检：`python tools/normalize_exercises.py report`（校验题号↔答案条数、选项 A–D 完整性、汉字集合差），有异常先修文件再出题。
  - 旧文件都在 `习题/.bak-<时间戳>/`。
- 法条引用务必经 `law-verifier` 或 `kb/laws/` 核对。
