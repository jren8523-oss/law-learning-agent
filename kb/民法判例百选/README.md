## 使用说明

- 已清洗：100 案标题统一为 `## NNN 标题`，案名＋案号行已回填；每案固定四小节 `### 事实概要 / 判决要旨 / 评析 / 参考文献`，评析下子目为 `#### Ⅰ/Ⅱ/Ⅲ/Ⅳ`。
- OCR 局限：原书图表、表格、示意图无法转文字（仅保留图注文字）；个别 OCR 误字（如人名「解亘」原误作「解巨」）已勘校。
- 案例所引法条以案例发生时的旧法为主（《民法通则》《合同法》《物权法》《侵权责任法》等）；讲原理按本书，**法条落地一律以大陆现行《民法典》条文为准**（law-verifier 只锚民法典）。
- 本书为「专题参考」角色：case 模式素材用，不进判分链、不挂章节进度。
