## 开场白：课程内容概览

**法典体系 ≠ 理论体系。** 学债法不是只背民法典条文。民法典只有「法典体系」（立法者制定的规则，实证法），而我们要学的是「理论体系」（教义学体系），它是百年不变的原理。

- 债法在民法典里没有独立一编（历史上单行法时代先有合同法、后有物权法、侵权责任法，2020 年民法典把它们拼在一起，从未有过"债法编"）。
- 但学理上仍有「债法总论」：把合同、无因管理、不当得利、侵权这几个具体债的**共同规则**抽取出来。共同规则藏在**合同编通则**里——通则有时用"合同当事人"，有时用更抽象的"债权人/债务人"，用"债权人/债务人"时，该规则就不仅适用于合同，也适用于法定之债。
- 张焕然体系：债法 = 债法总论 + 合同法 + 无因管理与不当得利 + 侵权法；其中债法总论采「提取公因式」模型（一个债权人 + 一个债务人正常履行完毕为模型，其余为对模型的修正）。
- 教学顺序：按**理论体系**学，讲到某规则时再看我国法条——法条顺序会被打乱，但内在逻辑完整。目的是让知识"定位"在体系里，遇到纠纷能迅速找到争议点。

## 第一章 债法导论

### 第一节 生活中的债 vs 民法上的债

先区分，再给定义。生活中的"债"很泛化：欠钱（债台高筑、父债子还）、人情债、情债、血债……含义已泛化为"亏欠某种东西"。德语里（Schuld）同样泛化，可指钱、也可指感情。

**三个关系问题**（学完债的发生原因再回答）：
1. 民法上的债与生活中的债是什么关系？——**有交叉**（借款合同等跟钱有关的合同是重合部分）。
2. 生活中的"债"是否带贬义/道德指责？——**否**，民法上的债是中性描述：一方依法律有义务为或不为一定行为，不含道德贬义。

民法上的债的范围要**框定清楚**：同一个词在不同领域含义不同，学债法只学民法上的债（意定+法定），不学"情债""笔债"。

### 第二节 债的发生（原因）

从具体事例抽象出体系。例子：

| 事例 | 法律定性 | 法条 |
|---|---|---|
| 老人立遗赠把财产送给同事女儿 | 单方行为（遗嘱/遗赠）→ 债权 | §1123 |
| 买 LV 包包（买卖合同） | 双方行为 → 债权债务 | — |
| 缔约过程中一方过错致他方受损 | 缔约过失 → 损害赔偿 | §500① |
| 快递小哥救火受伤（无义务却帮了别人） | 无因管理 → 赔偿 | §979① |
| 转账多转 900 元 | 不当得利 → 返还 | §985 |
| 打伤他人 | 侵权 → 损害赔偿 | §1165 |

**共性**：所有例子最终都变成"一方可以向另一方请求为一定行为"。

**体系化（两大块）**：
- **意定之债**：有当事人意思参与——单方允诺（遗嘱/遗赠）+ 合同（双方行为）。
- **法定之债**：法律直接规定——缔约过失、无因管理、不当得利、侵权（还有其他，后讲）。

**悬赏广告**（有争议，考试不考定性）：单方允诺说 vs 合同说。中国政法大学姚辉（姚彬彬）教授主张一种新的"合同说"。这类学理争议是写学年/期末论文的选题来源。

**债的通俗理解**：债务人"欠"债权人的某个东西（不一定是钱，也可能是别的给付）。

### 第三节 债的要素

任何债都必备的要素（=各种具体债的共性）：

1. **主体**：债权人 + 债务人（前三章默认一人，后章才加入多人/变更）。
2. **内容**：债权 + 债务。
3. **客体**：债务人的**特定行为**（作为或不作为），法律上叫**给付**；注意客体是行为，不是债务人本人，也不是标的物（标的物不一定有，如委托合同只有标的行为没有标的物）。

**债权**（§118②）：因合同、侵权、无因管理、不当得利及法律的其他规定，权利人请求特定义务人为或不为一定行为的权利。

**债权 vs 物权（四区别）**：
| | 债权 | 物权 |
|---|---|---|
| 权利客体 | 特定人的给付行为 | 物（例：权利质权时是权利） |
| 实现方式 | 请求性 | 支配性 |
| 效力范围 | 相对性/对人性（有例外） | 绝对性/对世性 |
| 并存关系 | 平等性/共存性 | 排他性/优先性 |

（例：同一电脑卖给两人，两个买卖合同均有效、债权可共存；所有权则只有一个，物权有排他性。）

**债权的权能**：请求力、执行力、处分力、保全力等。
**不完全债权**（欠缺部分权能）：已过诉讼时效的债（仍有请求力、无强制执行力，= 自然债务）；赌债（法律不保护，无执行力）。

**债务与责任**：通常有债务即有责任；但可分离——自然债务（有债无责）、物上保证人（有责无债，如第三人为他人抵押，只负物权关系不负担债务）。

### 第四节 债的概念

定义：依法律行为或法律规定，特定当事人之间可以请求为特定行为（包括作为和不作为）的财产性民事法律关系。（考试不直接考定义，辅助理解。）

**广义债 vs 狭义债**（关键，反复强调）：
- 广义债：整个合同关系（如买卖合同）——里面包含多个具体的请求权。
- 狭义债：单个请求权（如"支付价款"这一个给付）。
- 债务人履行完后消灭的是**狭义债**；解除合同消灭的是**广义债**。
- 债法总论**默认讲狭义债**（具体请求权）；金钱之债、劳务之债等都是对狭义债的分类。

## 第二章 债的履行

> 本章三个问题：①债有哪些类型、各类型如何履行；②广义债中债务人的义务群；③所有债履行的原则。

### 第一节 债的类型及其履行规则

**分类的意义：类型不同，规则不同**（规则相同就不必分类）。

**（一）金钱之债 / 非金钱之债**（按狭义债的标的）：
- 金钱之债三特殊规则：①**无免责事由**——§579 无任何条件/免责事由，欠钱始终要还，不因不可抗力免责（"谢某地震房屋被毁仍须还钱"）；②**可转化性**——实物债违约后转化为金钱债（违约金/损害赔偿）；③**流通性**——金钱债权流通性强，一般不受当事人限制约定束缚（第四章详讲）。
- 非金钱之债再分：**实物之债**（有具体实物）+ **劳务之债**（仅付出劳务）。
- **劳务之债三特殊规则**：①原则上**债务人亲自履行**，未经债权人同意不得第三人履行（月嫂、歌手演唱会——高度人身性、信赖关系）；②**不适用强制履行**——§580①第一项（债务标的不适于强制履行），只能请求损害赔偿；③债权人通常有**任意解除权**（如承揽合同 §787：定作人可随时解除，造成损失应赔偿）。

**（二）按履行地点分类（赴偿/往取/寄送之债）**（德国法学家耶林 1861 年提出）：
- **赴偿之债**（债权人所在地履行）：上门服务、外卖、送货上门——债务人到债权人处。
- **往取之债**（债务人所在地履行）：到店自取、堂食、看电影——债权人到债务人处。
- **寄送之债**（交给独立承运人即完成）：国际贸易指定港口交货承运人——给付地与结果地分离。
- 注意：淘宝卖家寄送不是寄送之债，因为他本有送货义务，属赴偿之债；只有"无直接送货义务、仅交独立承运人"才是寄送。
- 履行地点意义：①错误地点履行=未履行；②影响种类之债特定化时点→风险转移；③§514 金钱以实际履行地法定货币履行；④民事诉讼法管辖（§24 合同履行地法院）。
- **履行地点确定**：有约定从约定 → §510 协议补充/交易习惯 → §511③：给货币的在接受货币一方所在地；不动产在不动产所在地；**其他标的在履行义务一方（债务人）所在地**（例：买家具未约定送货，家具是动产非货币，→ 债务人 b 所在地，a 上门取货）。

**（三）特定之债 / 种类之债**（对实物之债的再分类）：
- 标准：物是否独一无二。特定之债=独一无二（房屋、**二手车买卖是特定之债**——常考点）；种类之债=可替代（同型号手机）。
- 种类之债特殊点：①**履行不能标准更高**——§580①第一项，种类物同类可替代，原则上不构成履行不能（当当买书路上被泥石流损毁，商家仍须重新发货）；除非同类物全部灭失或被法律禁止买卖。②**特定化后风险才转移**——特定化时点依履行地点：赴偿之债=送至债权人处可供受领时；往取之债=种类物分离完成并通知债权人；寄送之债=交给独立承运人时。

**（四）一时性之债 / 继续性之债**（看时间是否影响给付总量）：
- 一时性：总量确定（买卖、赠与，分期付款仍是总价确定=一时性）。
- 继续性：随时间增加（租赁、保管、仓储、供水供电；"每月月初送十箱直到叫停"）。
- 意义：解除规则不同——继续性关系除法定解除外有**任意解除权**（当事人须能跳出持续关系）。

**（五）简单之债 / 选择之债**（看给付可否选择）：
- 例：考上法大送"一台电脑或手机"=选择之债；送"一部手机"=简单之债。
- 选择权：原则归**债务人**（§515①），可约定债权人；**选择权未行使经催告仍不行使则转移至对方**（§515）。
- §516：可选择标的发生履行不能，选择权人不得选不能履行的标的；但该情形由对方造成的除外（可仍选该标的→转化为违约损害赔偿）。

### 第二节 债务关系中的义务群

目光从债权人转到债务人的义务，进行大分类：

**（一）主给付义务 / 从给付义务 / 附随义务**（按对债权实现的作用）：
- 主给付：决定债的类型、实现债权主要利益（买卖中交付汽车+支付价款）。
- 从给付：辅助实现（交付使用说明书、单证——§599）；来源：法律规定、约定（合并时交客户名单）、诚信原则（买车附送一点汽油）。
- 附随义务：保障债权人固有利益不受损害（§509②通知/协助/保密等），源于诚信原则。
- 区分要点：**主/从给付可诉请强制履行**；附随义务不可诉请履行、违反只发生损害赔偿；主给付不履行才可行使双务合同抗辩权（从给付原则上不行，除非致合同目的不能实现）；违反从给付原则上不能解除合同（除非不能实现合同目的）。

**（二）原给付义务 / 次给付义务**：原本约定的给付 vs 因不履行转化而来的给付（违约损害赔偿、恢复原状）。

**（三）手段债务 / 结果债务**（法国法概念）：
- 手段债务：只要求做出给付行为（医疗服务、家教——"已尽力"即履行，结果不重要）。
- 结果债务：必须出现特定结果（修车、绘画、拍照——没修好就是违约）。
- 意义：违约判断标准不同；归责原则不同（手段债原则上过错、结果债往往严格）。

**（四）先合同义务 / 后合同义务**（按义务存在的阶段）：先合同=缔约过失（§500-501，诚信原则）；后合同=合同终止后（§558 通知/协助/保密/旧物回收）。

**（五）不真正义务**：债权人负担、不可被诉请履行的"义务"（§591① 非违约方防止损失扩大义务）——违反后果是自己承受不利，不能就扩大损失请求赔偿。严格说不是义务（是负担）。

### 第三节 债的履行原则

- **全面履行原则**（§509①）：正确履行主体（原则债务人本人）、标的（质量/数量/价款）、地点（赴偿/往取/寄送）、期限、方式。
- **诚信履行原则**（§509②）：附随义务、先/后合同义务、不真正义务均由此导出；无履行先后应同时履行；情势变更（§533）基础。
- **绿色原则**（§509③）：节约资源、保护环境（§619 等）。
