# 债法线习题册（法大期末真题）

> 题源：法大《民法学原理二：债法》历年期末真题（2011—2025，去重后 17 份）。
> 口径：**法大口径**。答案优先用真题自带解析（刘家安/戴孟勇/缪宇/寇广萍/刘智慧等老师）；无答案的年份由 agent 按**张焕然《债法课件》学说 + 大陆《民法典》条文**整理，逐条标注来源。
> 用途：债法线（主线＝张焕然骨架 + 解亘填充）的**刷题题库**。出题只读「题目」，作答前绝不泄露「答案」。

## ⚠️ 判分弹性（重要）

与民法总线「杨代雄习题集＝答案确定、必须按它的答案判分」**不同**，本题库答案**非唯一标准**：
- 单选（有官方答案的年份）→ 可硬判对错；
- 名词解释/简答/论述/案例（无官方答案、按张焕然课件补答的）→ **看要点、言之成理即给分**，不抠字面；
- 无官方答案年份的参考答案仅作「要点提示」，不当作唯一标准答案。

## 约定

- 题 / 答案**分离存放**：`-题目.md` 与 `-答案.md` 成对。
- 每题标注【考点】，用于上课时按考点抽题。
- 民法典（2021-01-01 生效）前的年份标 ⚠️旧法，答案已附民法典对应条文。
