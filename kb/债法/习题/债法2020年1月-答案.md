# 债法 2019 秋期末（2020 年 1 月，无答案）· 答案

> 按张焕然课件学说 + 民法典整理（原题民法典前，已按民法典作答）。

## 二、名词解释

1. **预约**：约定将来订立特定合同的合同（§495）；违反预约应承担违约责任。
2. **不安抗辩权**：应先履行一方有确切证据证明对方有丧失或可能丧失履行能力的情形，可中止履行并通知对方（§527）。
3. **债的保全**：为防止债务人责任财产不当减少、保障债权实现，赋予债权人对债务人处分财产行为的干预制度，含代位权与撤销权（§535—542）。
4. **不当得利**：没有法律根据取得利益，致他人受损，应返还取得的利益（§985）。
5. **无过错责任**：依照法律规定，不论行为人有无过错，只要其行为/管领之物造成损害即承担侵权责任（§1166）。

## 三、法条分析题：债的定义之变迁

- 旧《民法通则》§84：以「**合同约定或法律规定**」为债的发生根据，强调「当事人之间特定的权利义务关系」。
- 新《民法总则》§118：以「**债权人请求特定义务人为或不为一定行为**」界定债权，明确债的发生原因（合同、侵权、无因管理、不当得利、法律其他规定），突出债的**相对性/对人性**。
- 两项核心论题：①债的相对性（债权是对特定人的请求权）；②债的发生原因法定性（意定之债 vs 法定之债）。

## 四、简答题

1. **种类之债的特定化（风险负担）**：种类之债在标的物**特定化**前不发生履行不能，风险由债务人承担；特定化（债务人完成交付所必要的行为、分离并通知等）后风险转移。画作被风卷走时已完成并特定化（打包签名置于案上、甲应约取画），故风险由债权人甲承担，甲仍应付款；乙无须再作（已特定化后灭失）。
2. **情势变更构成要件**（§533）：①合同成立后基础条件发生重大变化；②无法预见；③非商业风险；④继续履行对一方明显不公平。
3. **一般侵权构成要件**：①加害行为；②损害；③因果关系；④过错（故意或过失）。四要件齐备方构成一般侵权责任（§1165Ⅰ）。

## 五、案例题

1. **远某**：可向信鸽协会（咕咕厚的**管理人**）或咕爷（饲养人）主张**饲养动物致害**的无过错责任（§1245）。远某徒手抓鸽属重大过失的，可减轻责任。
2. **谢某**：可向香某（咕咕德的占有人/管理人）主张动物致害责任（§1245，咕咕德俯冲引发）；谢某对自家哈士奇受惊也负一定责任，可适当减轻香某责任。
3. **咕爷可向协会主张**：①协会将病鸽与咕咕明同笼，违反妥善保管义务，致 19 只鸽子感染，应赔偿 2000 元（违约/侵权）；②协会援引的免责条款系**格式条款**，不合理免除自身责任（§497），且属「一方不合理免除己方责任」的情形，**无效**；咕爷的誊抄不改变其格式条款性质与提示说明义务之不足。
4. **咕爷向喵某支付 0 元**：喵某摘脚环、改名，明知该鸽有主仍占为己有，系**恶意**（无权占有/恶意得利人），不得请求偿还费用；且须返还鸽子及奖金 1500 元（不当得利）。鸽笼、饲料、教材、报名费均非咕爷应负担。
5. **柯某**：可向「安氏烧鸽」餐厅主张——①餐饮合同**违约责任**；②缺陷食品致害的**产品责任/食品安全责任**（§1202/1203，可向生产者或经营者主张），请求赔偿 3000 元医疗费等。厨师甲/餐厅另对咕爷构成侵害其鸽子所有权的侵权责任。
6. **申某**：可向咕爷主张 1000 元酬谢。悬赏广告系单方允诺，申某完成「提供线索」的指定行为即有权请求报酬，咕爷不得以鸽子已被吃、无法返还为由拒付。
