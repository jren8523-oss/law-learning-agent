# 债法 2018 秋期末（含解析·刘家安）· 答案

> 真题自带刘家安老师解析（旧法条）。已附民法典对应条文。

## 二、名词解释

1. **不当得利**：无法律根据取得利益致他人受损，应返还（旧《民法通则》§92 → 民法典 §985）。
2. **缔约过失**：订立合同过程中一方违反先合同义务致对方信赖利益受损的赔偿责任（旧《合同法》§42 → §500）。
3. **提存**：因债权人原因债务人难以履行时，将标的物交提存机关以消灭债务（旧《合同法》§101 → §570）。

## 三、简答题

1. **债权人代位权构成要件**：①债权人对债务人的债权合法；②债务人怠于行使其到期债权（或从权利）；③损害债权人的债权实现；④非专属于债务人自身的权利（→ §535）。
2. **要约失去效力的情形**：①要约被**撤回**（发出后、到达前）；②要约被**撤销**（到达后、承诺前，但§476 不可撤销情形除外）；③承诺期限届满受要约人未承诺；④受要约人**拒绝**；⑤受要约人对要约内容作出**实质性变更**（视为新要约）。

## 四、法条分析题：多重买卖合同的效力（刘家安解析）

- 关键：买卖合同是**债权合同**，其效力不以处分权为必要（**负担行为与处分行为区分**）；债权具有**非排他性/平等性**，数个内容相同的债权均指向同一债务人，并不违反逻辑。
- 故多重买卖合同**均有效**；出卖人对任一买受人不履行（不能取得所有权）的，依《合同法》§107（→§577）承担**违约责任**。
- 常见失分点：误把笔墨花在「合同无效」与违约责任形态上，而未点出债权合同属性与负担/处分行为区分。

## 五、案例题

### （一）小远网店案

1. 小远及时验收并通知瑕疵（→§621），可主张更换、减价、退货等（旧《合同法》§111 → §582）；并可依顺序履行抗辩权（§67 → §526）拒付 1 万元价款。
2. 电商平台销售信息**符合要约条件**的，用户提交订单成功即合同成立（《电子商务法》§49Ⅰ）；成立后，小远的标价错误属**表示错误（重大误解）**，可**撤销**该合同（→§147）。
3. **有权**。小晶是债权受让人，且债权转让已通知小远（→§546）。
4. **有理由**。债务人得以对让与人（小雷）的抗辩事由对抗受让人（小晶）（→§548）。
5. 小晶**有权**要求小宇承担保证责任（一般保证的保证人），但小宇可：①主张**先诉抗辩权**（一般保证，须先就小远财产强制执行）；②主张主债务人的抗辩，就霉变货物 1 万元**拒绝**承担保证责任（→§687、§701）。

### （二）萨维尼柴犬案

1. 甲**无需个人担责**（第一方案）：甲执行工作任务致害，由**用人单位（生活馆）**承担侵权责任（旧《侵权责任法》§34 → §1191）。第二方案（甲有重大过失时与雇主连带、雇主可追偿）可作为补充。
2. 柯基 3000 元与萨维尼 2000 元**均由生活馆承担**：违反管理规定未对动物采取安全措施致害，饲养人/管理人承担**无过错责任**（旧《侵权责任法》§79 → §1246）；萨维尼部分因生活馆的履行辅助人（甲）过失，生活馆承担违约损害赔偿责任。
3. **可以**。8.16 后双方按「合同关系延续说」类推不定期合同（旧《合同法》§236 → §734）继续成立照看关系，生活馆应对继续治疗费 1000 元负责（按无因管理说亦须以善良管理人注意义务负责）。
4. **黑博士承担**。依合同延续说，支付托管费是其主给付义务（按无因管理说反而难自圆其说，因托管费是报酬而非管理费）。
5. **该格式条款不生效力**：生活馆对免责条款未尽提示说明义务（旧《合同法》§39），相对人可主张该条款未订入合同/可撤销；并可依 §40 主张**无效**（→§496/497）。
