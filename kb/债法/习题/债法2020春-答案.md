# 债法 2020 春期末（回忆版，无答案）· 答案

## 一、案例题

1. **甲公司可继续请求交付**：口罩为**种类物**，交付前因泥石流灭失，因尚未特定化（未交付、未区分），债务人不得以「履行不能」免责，仍须以同种类物继续履行（种类之债不因种类物灭失而消灭）。
   **口罩厂不能请求甲公司支付价款**：标的物未交付，价金风险未转移（§604 交付主义），甲公司无付款义务（甲公司封闭无人并非「无正当理由拒绝受领」，不构成受领迟延）。

2. **乙医院对口罩厂的权利**：
   - 口罩厂交付的标的物不符约定（把一次性口罩当医用外科口罩）→ **瑕疵给付**，乙医院可主张更换、减价、退货、修理及**违约损害赔偿**（§577/582）；
   - 因口罩防护不足致医生 Y 感染 → 属瑕疵导致的固有利益损害，可请求**违约损害赔偿**（加害给付）；
   - 乙医院多汇的 90 万元（10 万误写 100 万）→ 口罩厂构成**不当得利**，乙医院可请求返还（§985）。

3. **侵权责任**：
   - 司机 A 返程遭泥石流受伤 → 泥石流属不可抗力，无人担侵权责任（A 的损害走工伤保险）。
   - 司机 B 接打电话撞伤路人 L、致 K 受伤 → B 系口罩厂工作人员、执行工作任务，由**用人单位口罩厂**承担侵权责任（§1191）；L、K 可向口罩厂主张。
   - 医生 Y 因缺陷口罩被感染 → 属**缺陷产品致害**，Y 可向生产者（口罩厂）主张**产品责任**（§1202），乙医院亦可就自身损失主张违约责任。

4. **村民 C 与口罩厂**：C 无义务而救援司机 A → 成立**（正当）无因管理**，C 可请求口罩厂偿还必要费用（送医费用、衣物损失、擦伤医疗费）（§979）。但 C 整理口罩时**粗心大意致污染** → 违反善良管理人注意义务，对口罩厂承担损害赔偿责任（§983 违反适当管理义务），两相可抵销。

## 二、论述题：我国民法债法体系（民法典立法技术）

- **立法技术**：《民法典》未设形式上的「债法总则/债法通则」，而以「**合同编通则**」作为**实质债法总则**，通过 §468「非因合同产生的债权债务关系……适用本编通则的有关规定（依其性质不能适用的除外）」将合同编通则的规则适用于无因管理、不当得利、侵权等非合同之债。
- **体系**（张焕然「提取公因式」模型）：债法＝**债法总论**（债的履行/保全/移转/消灭/多数人之债/担保）+ **债法分论**（合同法 + 无因管理、不当得利 + 侵权法）；债法总论以一个债权人与一个债务人正常履行完毕为模型，其余是对该模型的修正。
- **评价**：该体例避免了「债法总则」立法争议，通过提取公因式实现债法规则的统一适用，同时保留合同编的独立性。
