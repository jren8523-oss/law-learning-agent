# 第一章 债的概述

> 校课 PPT 讲义（马工程《民法学》口径，老师陈安然）。72 页。
> 🔗 主线对应：解亘《板书体债法总论》第1部「债的基本概念」。
> ⚖️ 口径：本讲基本是通说，与解亘/王泽鉴无立场分歧；仅「缔约上的过错」＝通说「缔约过失责任」的译名差异。

## 第一部分 债的概念、特征和要素

### 一、债的概念

- 债是**特定人之间**请求为一定行为或不为一定行为的关系（《民法典》§118Ⅱ）。
- 狭义的债的关系＝个别的给付关系；广义的债的关系＝各狭义债关系的总和（如买卖合同＝交付房产之债＋支付价款之债）。
- 广义债关系两特点：①架构复杂（债权债务＋权能、限制）；②随时间推移不断变动。
- 来源：罗马法「法锁」。我国民间"债"仅指金钱债务；现行法上债＝以债权债务为内容的民事法律关系。

### 二、债的特征（6 点）

1. 是民事法律关系（区别于生活关系）
2. 是**财产法律关系**（无财产给付内容的从债法剥离）
3. 是**特定主体之间**的法律关系（＝债的相对性，§118Ⅱ）
4. 是一方向另一方**给付**的法律关系（给付是核心）
5. 债权在效力上具**平等性**（有担保物权的优先受偿，其余按比例平等受偿）
6. 发生原因**多样性**

### 三、债的要素

**主体**：债权人／债务人（多数场合双方既享有债权又负债务，对立依存）。

**内容**：债权、债务及权能、限制。

#### （一）债权

- 特点：①请求权（但债权≠请求权：请求权还有物权请求权等；债权还有受领、选择、解除、终止等权能）；②相对权；③相容性＋平等性。
- **债权 vs 物权**（7 点区别）：

| | 债权 | 物权 |
|---|---|---|
| 性质 | 请求权 | 支配权 |
| 效力范围 | 对人权、相对权 | 对世权、绝对权 |
| 效力关系 | 平等性 | 优先性 |
| 公开性 | 非公开 | 公开化 |
| 设立 | 自由约定 | 法定主义 |
| 客体 | 以行为为主 | 以有体物为主 |
| 存续 | 有一定期限 | 永久性或长期性 |

- 债权四项权能：给付请求权（请求力）、给付受领权（保持力）、债权保护请求权（强制执行力）、处分权能（抵销／免除／让与）。
- **完全债权**（四效力齐备）vs **不完全债权**（欠缺某项效力）；但**不得欠缺保持力**，否则不再是债权。

#### （二）债务

- 分类：
  - 作为债务 vs 不作为债务
  - 完全债务 vs 不完全债务
  - **主给付义务**（决定债的类型、固有必备）／**从给付义务**（补助主给付、确保利益最大满足；来源：法律明文、当事人约定、诚信原则＋补充解释）／**附随义务**（§509Ⅱ 通知协助保密，诚信原则产生）
- 附随义务与主给付义务三区别：①主给付自始确定并决定债类型，附随随关系发展形成；②主给付构成对待给付（可生同时履行抗辩），附随原则上不构成；③不履行主给付得解除合同，不履行附随原则上不得解除（仅损害赔偿）。
- **不真正义务**（间接义务）：不得请求履行、违反不赔偿、仅使负担方权利减损（例 §591Ⅰ 减损义务）。
- **先合同义务**（缔约时诚信，违反→缔约过失责任）与**后合同义务**（§558 合同终止后）。

#### （三）债的客体

- 债的客体（标的）＝**给付**（作为＝积极给付；不作为＝消极给付）。
- **给付 vs 履行**：给付是应为行为的抽象；履行是实施行为的具体。
- **标的 vs 标的物**：标的＝给付本身；标的物＝行为所及于的物（纯劳务之债无标的物）。
- 给付须**合法、确定、适格**。

## 第二部分 债的发生原因（7 种）

1. **合同**（§464；婚姻收养监护等身份协议排除）
2. **缔约上的过错**（＝缔约过失：缔约中过错致合同不成立/无效/被撤销/不追认，赔偿对方损失）
3. **单独行为**（单方允诺；悬赏广告性质之争＝单独行为 vs 要约）
4. **侵权行为**（侵权责任关系＝债）
5. **无因管理**（§979 管理人无义务为避免他人受损而管理）
6. **不当得利**（§985；三种除外：道德义务给付／债务到期前清偿／明知无义务仍清偿）
7. **其他**（拾得遗失物保管交还、遗嘱执行等）

## 第三部分 债法在民法中的地位及体系

- 物权法＝维护"静的安全"；债法＝规范保护促进财产流转、"动的安全"。
- 债法体系＝债法总则＋合同法＋侵权责任法＋不当得利＋无因管理＋单方允诺（我国合同法、侵权责任法独立成编）。

## 第四部分 债的分类（8 组）

1. **法定之债**（侵权/不当得利/无因管理，内容由法律定）vs **意定之债**（合同/单方允诺，任意性规范为主）
2. **主债** vs **从债**（如借款＝主债、保证＝从债；主债不成立/无效/消灭→从债随同；从债瑕疵不牵连主债）
3. **特定之债** vs **种类之债**（种类之债标的物须特定后才能履行；种类物原则上不因毁损灭失而履行不能）
4. **简单之债**（单一标的）vs **选择之债**（数个标的择一；选择权＝形成权，行使后不得撤回、效力溯及债发生时；无约定时选择权一般属债务人）
5. **单一之债** vs **多数人之债**（多数人之债＝连带/按份/不真正连带）
6. **按份之债**（§517，份额难以确定视为相同）vs **连带之债**（§518，法定或约定；法定连带＝共同侵权 §1168、代理人与相对人恶意串通 §164Ⅱ）
7. **可分之债** vs **不可分之债**（不可分债务原则上适用连带债务规定）
8. **金钱之债** vs **非金钱之债**（区别：标的物／能否履行不能／履行方式／能否约定利息／转让限制）

### 连带债务的效力（§519、§520）

- **对外效力**：债权人可向一人/数人/全体请求，同时/先后，全部/部分。
- **就一人所生事项效力**（§520）：履行/抵销/提存→其他债务人相应范围消灭；免除→应承担份额内其他债务消灭；债权债务同归一人→扣除份额后继续存在；受领迟延→对其他连带债务人发生效力。
- **对内效力**（§519）：份额难以确定视为相同；超过自己份额者可就超出部分追偿并代位享有债权人权利（不得损害债权人利益）；被追偿者不能履行→其他连带债务人按比例分担。
