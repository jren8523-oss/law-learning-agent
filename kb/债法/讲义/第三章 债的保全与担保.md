## 第一部分 债的保全

### 债的保全概述

- 债的保全＝防止债务人责任财产不当减少、保障债权人债权实现的法律制度（§535—542），含**债权人代位权**与**债权人撤销权**两项。
- 分工：**代位权**着眼于债务人的**消极行为**（有权利行使而不行使）；**撤销权**着眼于债务人的**积极行为**（实施减少财产、损害债权实现的行为）。

### 一、债的保全的概念与特征

**概念**：为防止债务人不当行为导致其责任财产减少、危害债权人债权实现，债权人出于保全自己债权而干预债务人自由处分财产的法律措施。

三个特征：

1. **是债的对外效力的体现（债的相对性的例外）**
   - 债务人的全部财产是其履行债务的最后保障＝债务人的「**责任财产**」。
   - 债务人与第三人的不当行为致责任财产减少、影响债权实现的，法律介入干预 → 债权效力及于第三人行为/财产，构成债的相对性之例外。
2. **目的在于实现债权价值**：促使责任财产增多或避免减少，增加债权实现的可能性。
3. **发生于债有效成立后至履行完毕前**：合同不成立、无效、被撤销、被解除的，不能适用债的保全。

### 二、债的保全的性质与功能

**性质**：

- 责任财产是债务人履行债务的**一般担保**；债的保全是法律允许债的效力及于第三人的制度。
- §468：保全制度**不以合同债权为限**——基于无因管理、不当得利、侵权等产生的债权亦可适用。
- **区别于程序法上的财产保全**：财产保全（查封/扣押/冻结）是**程序法**制度、不改变实体权利义务、一般需申请；债的保全是**实体法**制度，代位权、撤销权都是实体法权利。

**功能（vs 债的担保）**：

1. 担保以**特定财产或特定人信用**确保债权实现；保全通过**促使责任财产增加或避免不当减少**提高实现可能性。
2. 担保的缺陷：抵押需登记（成本高）、质押需移转占有（影响利用）、留置限于特定债权、保证难找保证人且保证人责任财产也可能减少；且担保难以回应「财产应增加而未增加 / 不当减少」。保全在这些情形下更简便。

### 第一节 债权人代位权

#### 一、概念

- **债权人代位权**：债务人怠于行使其对第三人（**次债务人**）的权利而危及债权实现时，债权人为保全债权，**以自己名义**代位行使债务人对第三人权利的权利。
- 由法律直接规定，随债权产生/转移/消灭而转移/消灭。
- 目的不是扣押债务人或优先受偿，而是增强债务人履行能力。
- 性质：是债权对外效力、债权法定权能（无需约定）；但因源于债务人对次债务人的权利，而非依债权人单方意思形成法律效力 → **不属于形成权**。

#### 二、行使条件（§535Ⅰ + 五项）

§535Ⅰ：「因债务人怠于行使其债权或者与该债权有关的从权利，影响债权人的到期债权实现的，债权人可以向人民法院请求以自己的名义代位行使债务人对相对人的权利，但是该权利专属于债务人自身的除外。」

1. **债权人对债务人的债权合法**：无合法债权债务关系 → 无代位权基础。
2. **债务人须对第三人享有权利**：以债务人对第三人的债权为标的。
   - 可代位范围（§535Ⅰ：债权 + 与该债权有关的从权利）：
     - ①债权（合同债权、不当得利、无因管理等所生债权）；②担保权；③以财产利益为目的的**形成权**（解除权、撤销权、抵销权等，**存在争议**）；④以财产利益为目的的让与权、清偿受领权；⑤诉讼上的公权利（起诉、申请强制执行、申请注销登记）。
3. **债务人怠于行使权利**：应行使+能行使而未行使的**客观状态**，不问主观过错。
   - 《合同编通则解释》§33：债务人不履行到期债务，又**不以诉讼或仲裁方式**向相对人主张债权/从权利，致债权人到期债权未实现的，认定为「怠于行使」。
4. **危及债权人的债权实现**：债务人责任财产充足则无必要。
   - **到期前例外（§536）**：债务人的债权/从权利存在**诉讼时效即将届满**或**未及时申报破产债权**等情形、影响债权实现的，债权人可代位向相对人请求向债务人履行、向破产管理人申报或作出其他必要行为（条件更严）。
5. **债务人对第三人的权利不具有专属性**：
   - 《合同编通则解释》§34（专属自身的权利）：①抚养费/赡养费/扶养费请求权；②人身损害赔偿请求权；③劳动报酬请求权（**超过债务人及其所扶养家属生活必需费用部分除外**）；④基本养老保险金、失业保险金、最低生活保障金等；⑤其他专属权利。

#### 三、行使范围与方式

**范围**：

- 行使主体：债权人；多个债权人可各自/共同行使，但**同一债权一人行使后其他人不得再就该债权行使**。
- 须以**自己名义**（不同于代理，代位权诉讼中债权人具原告资格）。
- 范围以债权人的**到期债权为限**（§535Ⅱ），不得代位行使全体债权人债权；客体以债务人现有财产权利为限（「债权 + 从权利」）。

**方式（两种）**：

1. **诉讼方式**（§535Ⅰ，一般情形）。
2. **到期前的直接/必要行为**（§536，特定情形：时效届满/未申报破产债权等）。

#### 四、行使效力

- **对债务人**：客体范围外或超过代位请求数额的部分，债务人仍可处分；**必要费用由债务人负担**（§535Ⅱ，从所得利益中**先行扣除**）。
- **对第三人（次债务人）**：法律地位不受影响；不得以与债权人无合同关系抗辩；**相对人对债务人的抗辩可向债权人主张**（§535Ⅲ）。
- **对债权人**：「入库规则」vs「直接受偿规则」之争 → **§537 采直接受偿规则**：代位权成立，由相对人向债权人履行；接受履行后，债权人与债务人、债务人与相对人之间相应权利义务终止；但债务人的债权/从权利被保全、执行或债务人破产的，依相关法律规定处理。行使代位权的债权人原则上**优先受偿**。

### 第二节 债权人撤销权

#### 一、概念

- **债权人撤销权**：为保全债权，对债务人与第三人实施的危及其债权的行为，**请求法院予以撤销**的权利。
- 依据是法律直接规定，而非合同权利义务。
- **性质**（学说）：形成权说 / 请求权说 / 责任说 / **折中说**（兼具请求权与形成权）。我国通说采**折中说**。
- **除斥期间（§541）**：自知道或应当知道撤销事由之日起 **1 年**；自债务人的行为发生之日起 **5 年**内未行使的，撤销权消灭。

#### 二、成立要件

**（一）客观要件（诈害行为）**

1. 债权债务关系成立**后**，债务人实施了处分财产行为（仅指**法律上的处分行为**，单方/双方行为在所不问）。
   - 可撤销行为（§538、539）：放弃债权、放弃债权担保、无偿转让财产、恶意延长到期债权履行期限、以明显不合理低价转让财产、以明显不合理高价受让财产、为他人债务提供担保。
2. 处分行为**导致责任财产减少**（以财产为标的 + 减少责任财产）。
3. 处分行为**影响到债权人的债权实现**（危及债权）。

**（二）主观要件（恶意）**

- 债务人 + 第三人主观恶意（明知影响债权实现仍为之）。
- **§538（无偿处分）**：放弃债权/放弃债权担保/无偿转让财产——除「恶意延长到期债权履行期限」需债务人恶意外，**其余只须客观要件，无须主观要件（包括第三人）**。
- **§539（有偿处分）**：明显不合理低价转让 / 明显不合理高价受让 / 为他人债务提供担保——须**同时具备客观要件 + 主观要件**（相对人知道或应当知道）。
- **债务人恶意**的认定：观念主义（认识后果即可，不必有诈害故意）vs 意思主义（须有诈害故意）。§539 采**观念主义**。
- **第三人恶意**：以**受益时**的主观状况为准；受益后才知情的，不能认定恶意，债权人不得撤销。

#### 三、行使范围与方式

- **范围**：以债权人的债权为限（§540）；任一债权人可单独或共同行使，效力及于全体债权人共同利益。
- **方式**：以**自己名义**；须**通过诉讼**（对第三人影响大、由法院审查），学理称「**形成诉权**」。

#### 四、行使效力（入库原则）

- 我国现行法未明定，实务采**「入库原则」**：撤销后财产归入债务人责任财产，作为全体债权人的共同担保。
- **对债务人**：§542——行为被撤销的，**自始没有法律约束力**（自始无效）。
- **对第三人（受益人）**：已受领财产的，负返还义务；不能返还或不必返还的，折价返还；其向债务人支付的代价可请求返还。
- **对债权人**：取回的财产/损害赔偿归债务人，全体债权人**按债权比例受偿**，行使撤销权者**不优先受偿**；但必要费用由债务人负担（§540，从所得利益中扣除）。

**解读·代位权 vs 撤销权**：撤销权（§542 自始无效）后能否一并提起代位权诉讼？——PPT 提出待讨论（撤销后债务人财产回复，若仍怠于行使债权，理论上可再行代位）。

## 第二部分 债的担保

### 债的担保概述

- **债的担保**：促使债务人履行债务、保障债权实现的法律措施。
- **一般担保**：债务人以**全部财产**作履行债务的总担保（非针对某一债，弱点：责任财产不足则全部/部分落空）。
- **特别担保**（通常所言担保）：
  - **人的担保** = 保证；**物的担保** = 抵押权、质权、留置权；**金钱担保** = 定金。
- **反担保（§387Ⅱ）**：第三人为债务人向债权人提供担保的，可要求债务人提供反担保；反担保＝为确保担保人承担担保责任后实现对债务人的**求偿权**而设，又称**求偿担保**。
  - 设立为民事法律行为，须符合 §143；方式限于**保证、抵押、质押**（各有特定成立要件）。
  - 成立条件：①以本担保存在为前提；②提供主体不限于债务人（含第三人）；③依具体形式满足特定成立要件。

### 第一节 保证

#### 一、保证的概念和性质

**概念**：第三人（保证人）和债权人约定，当债务人不履行债务时，该第三人按约定履行债务或承担责任的担保方式。保证人承担的债务＝保证债务（保证责任）。

**性质（5 点）**：

1. **从属性**：
   - 成立上的从属性（以主债成立为前提）；
   - 范围/强度上的从属性（保证范围、强度不得大于/强于主债务，超过则缩减至主债务程度；附条件主债务的无条件保证只成立附同一条件的保证债务；保证债务履行期早于主债务的约定无效；利息高于主债务的缩减至主债务利息）；
   - 转移上的从属性（主债权转移，保证债权原则上随之转移）；
   - 变更/消灭上的从属性（主债务消灭则保证债务消灭；主债变更保证债务一般随之，但不得增加范围强度）。
2. **独立性**：保证债务是**另一个独立的债务**（非主债务一部分），可约定仅担保一部分、有自己独立的变更消灭原因、保证人可单独行使自己的抗辩权。
   - 例外「**独立保证**」：不可撤销保函/见索即付保函/见单即付保函，独立于主债、保证人不享有债务人的抗辩权；票据保证为单方法律行为、具独立性。
3. **补充性**：主债务人不履行时，债权人方可请求保证人承担。
4. **单务、无偿性**：保证人单方负担债务，债权人无对待给付、无对价。
5. **要式性**（§685）：书面形式——单独书面合同 / 主债权债务合同中的保证条款 / 第三人单方书面保证（须债权人接受且未异议才成立）。

#### 二、债权人与保证人之间的关系

- **一般保证（§687）**：约定债务人**不能履行**债务时保证人才承担；主合同纠纷经审判或仲裁，并就债务人财产强制执行仍不能履行时，才承担。
- **连带责任保证（§688）**：保证人与债务人对债务承担连带责任；债务人不履行到期债务或发生约定情形，债权人可请求债务人履行，也可直接请求保证人承担。

**1. 债权人的权利**：请求保证人承担保证责任，以主债务人不履行 + 保证责任已届承担期为前提。
- 一般保证中，保证人享**先诉抗辩权**（强制执行为先）；不行使抗辩权的，债权人可对主债务人与保证人同时/先后主张，一方部分/全部清偿则相应缩减消灭。
- 连带责任保证中，无先诉抗辩权。

**保证期间（§692/693/694）**：

- 确定保证人承担保证责任的期间，**不变期间**（不发生中止、中断、延长，§692）。
- 一般保证：债权人须在保证期间内对债务人**起诉/申请仲裁**；连带责任保证：须在期间内**请求保证人**承担（§693）。未主张 → 保证人不再承担。
- 约定早于主债务履行期限或与其同时届满 → 视为没有约定；没有约定或约定不明 → 主债务履行期限届满之日起 **6 个月**；「保证责任直至主债务本息还清为止」类 → 视为约定不明。
- 起算：债务人不履行到期债务或发生约定情形之日；主债务履行期限无约定/约定不明 → 自债权人请求债务人履行的**宽限期届满之日**起算。
- **保证债务的诉讼时效（§694）**：一般保证——从保证人拒绝承担保证责任的权利消灭之日（即先诉抗辩权消灭）起算；连带责任保证——从债权人请求保证人承担保证责任之日起算。

**主合同变更（§695）**：履行期限变更未经保证人书面同意 → 保证期间按原约定/法定；其他变更——未经书面同意**减轻债务**的，仍对变更后债务承担；**加重债务**的，对加重部分不承担。

**债权转让（§696）**：应通知保证人；未通知，转让对保证人不发生效力；约定禁止转让而未经书面同意转让的，保证人对受让人不再承担。

**债务转移（§697）**：应经保证人同意；未经书面同意转移的，保证人对该部分不再承担（另有约定除外）。**第三人加入债务的**，保证责任不受影响（偿债能力只增不减）。

**一般保证特定免责事由（§698）**：主债务履行期届满后，保证人向债权人提供债务人可供执行财产的真实情况，债权人放弃/怠于行使致该财产不能执行的，保证人在该财产价值范围内不再承担。

**2. 保证人的权利**（抗辩/防御性权利）：

1. **援引债务人的抗辩（§701）**：主债务人所有的抗辩保证人均可主张；债务人放弃抗辩的，保证人仍有权主张。
   - 三类：权利未发生（主合同未成立）、权利已消灭（适当履行）、拒绝履行抗辩权（时效完成、同时履行、不安、先履行）。
2. **拒绝履行权（§702）**：债务人对债权人享有**抵销权或撤销权**的，保证人可在相应范围内拒绝承担。
3. **先诉抗辩权（§687Ⅱ，仅一般保证）**：例外——①债务人下落不明且无财产可供执行；②法院已受理债务人破产案件；③债权人有证据证明债务人财产不足以履行全部债务或丧失履行能力；④保证人书面放弃。
4. **基于一般债务人地位应有的权利**：保证债务单独消灭、未届清偿期、保证合同不成立/无效/被撤销、保证债务罹于诉讼时效等，均可抗辩。

#### 三、保证人与主债务人之间的关系

**1. 保证人的追偿权（求偿权）**：承担保证责任后向主债务人请求偿还。
- 成立要件：①已向债权人履行保证债务；②因履行使债务全部或部分消灭；③履行无过错；④无赠与意思。
- 性质：委托（适用委托合同）/ 无因管理（符合法律规定+社会常理+债务人正确意见的可请求本金利息必要费用，有损害可赔；违反则仅在债务人获利限度内）/ 赠与（明示不再追偿则无追偿权）。
- 时效：§188 的 **3 年**，自承担保证责任之日起算。
- 范围：①实际承担的保证责任；②自承担之日起给付金额的法定利息；③必要费用（履行、诉讼等）；④不可归责于己的其他损失。
- **共同保证**：按份共同保证——各按份额承担后在其范围内追偿；连带共同保证——各保证人有义务履行全部，履行后向主债务人追偿，不能追偿部分按内部约定比例分担、无约定平均分担；债务人破产、债权人未申报债权的，各连带保证人**作为一个主体申报债权**预先行使追偿权。

**2. 保证人的代位权（清偿受领权）**：承担保证责任后，在承担范围内**承受债权人对主债务人的债权**，行使原债权人的权利。
- 成立要件：①已向债权人承担保证责任；②对主债务人有追偿权。
- 效果：债权在清偿限度内**法定移转**于保证人（无须意思表示），但行使不得损害债权人利益。

### 第二节 定金

#### 一、定金的概念与特征

**概念**：为确保合同履行，依法律规定或约定，一方在合同订立时/订立后、履行前，按合同标的额一定比例，预先给付对方的金钱或其他代替物。属于**金钱担保**。

**特点（5）**：①标的为金钱或其他可替代物；②预先交付；③**实践合同**；④**从合同**；⑤双重功能（担保履行 + 制裁违约）。

**相近概念区分**：

- **定金 vs 预付款**：①定金是担保方式（非履行范畴），预付款是价金义务一部分（提前履行部分债务）；②定金交付形成独立从合同，预付款是履行主债一部分；③定金一般一次性，预付款可分期；④定金类型多（成立要件/证明/解约代价），预付款原则上无；⑤一方不履行且严重 → 适用定金罚则，预付款无此效力。
- **定金 vs 押金**：①担保对象不同（定金担保主合同主给付）；②数额不同（定金低于标的额且不得超法定比例，押金往往高于/等于被担保债权额）；③效果不同（定金有丧失/双倍返还效力，押金无）。
- **保证金**：种类性质复杂，需具体分析——①仅作付款备用金、无定金罚则；②名为保证金实为预付款；③依当事人意思+合同整体联系性属定金；④一方不履行归对方、对方不履行不负双倍返还。

#### 二、定金的种类

1. **成约定金**：作为合同**成立要件**（交付合同才成立）。
2. **证约定金**：以定金为**订立合同的证据**（非成立要件，仅证明合同成立；不能使无效/被撤销/不被追认的合同有效）。
3. **违约定金**（§587）：交付方不履行，接受方可没收；兼有证约作用。
4. **解约定金**：以定金为**保留解除权的代价**（交付方抛弃定金解约、接受方双倍返还解约）。
5. **立约定金**：为**保证正式缔约**（拒绝订约的，给付方无权要求返还、收受方双倍返还）。

#### 三、定金的成立

- 须意思一致 + **现实交付**，自**实际交付定金时成立**（§586Ⅰ后段）。
- 交付时间：立约定金须主合同订立前；成约定金原则上主合同订立前/成立时；证约定金通常与主合同成立同时；违约定金/解约定金可在主合同成立同时或成立后、履行前。
- **数额限制（§586Ⅱ）**：由当事人约定，但**不得超过主合同标的额的 20%**，超过部分不产生定金效力；实际交付多于/少于约定数额的，视为变更约定数额。

#### 四、定金的效力

**1. 定金罚则（§587）**：
- 给付方不履行/履行不符约定致合同目的不能实现 → **无权请求返还定金**；收受方同样情形 → **双倍返还定金**。
- 适用两种情形：①不履行债务（如明确拒绝履行）；②履行不符约定**致合同目的不能实现**（根本违约）。

**2. 定金与违约金（§588）**：同时约定的，一方违约时对方**只能择一主张**，不能并用（功能重合 + 叠加过重、违反诚信）。
