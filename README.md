# 学习 Agent 启动器

一个通用的 AI 辅助学习系统。法学是第一个用例，可以适配到任何学科。

## 这是什么

不是一门课，而是一套**学习操作系统**。你用 AI 客户端打开这个文件夹，它就会变成一个按页推着你走的老师——讲课件、带读教材、出题考你、帮你记账。

核心方法论来自一份 6000 字的手册：[`给朋友-经管学习agent手册.md`](./给朋友-经管学习agent手册.md)（建议先读这份，30 分钟就能跑通精简版）。

## 前置条件

- **[Kimi Code](https://kimi.com/download)**（或其他支持"项目约定"的 AI 客户端）—— 打开这个文件夹，`AGENTS.md` 自动生效
- **Python 3.11+**（可选，用于把课件转成逐页文本）—— `pip install pymupdf python-pptx`

## 3 分钟跑通

```bash
git clone <this-repo> my-course
cd my-course
# 用 Kimi Code 打开 my-course 文件夹
pi
```

1. 复制 `profile.example.md` → `profile.md`，填你的信息
2. 复制 `进程树.example.md` → `进程树.md`
3. 把课件放进 `material/课件/`，运行 `python tools/pdf2md.py` 转成逐页文本
4. 对 AI 说"开始上课"

## 架构速览

```
├── .pi/                    # 核心：扩展、skills、源卡（一源一卡）
│   ├── extensions/         # 菜单、判分、笔记镜像
│   ├── skills/             # teach-law（带读）、practice-law（做题）、visualize（图表）
│   └── sources/            # 每本书/每门课一张卡（frontmatter + 教法）
├── tools/                  # Python 脚本（pdf2md、pptx2md、OCR 等）
├── material/               # 你的素材（课件、录音、PDF）— 不进 Git
├── kb/                     # 你的知识库 — 不进 Git
├── notes/                  # 你的笔记 — 不进 Git
├── profile.md              # 你的画像 — 不进 Git（用 .example 模板填写）
├── 进程树.md               # 你的进度 — 不进 Git
└── 给朋友-经管学习agent手册.md  # 📖 先读这份
```

### 四种教学模式

| 模式 | 说明 | 触发方式 |
|---|---|---|
| **上课** | 双屏逐页对读：AI 报页号讲课件，你一页页推进 | 菜单选「上课」→ 选课节 |
| **阅读** | 精读教材：AI 带读 + 提问 + 笔记归档 | 菜单选「阅读」→ 选书/章 |
| **做题** | 选择题/案例题判分 + 错题复习 | 菜单选「做题」→ 选题库 |
| **汇总** | 每周五自动推荐：更新总账、周记、各线状态 | 周五打开时自动提示 |

### 三条学习线

- **上课线**：跟学校课程走，一份课件一节课
- **阅读线**：一本一本地精读教材，读完再定下一本
- **补缺线**：考纲里漏掉的部分，读到再定读法

## 适配到新学科

拿到这个仓库后，用 AI 帮你改（在 Kimi Code 里直接说）：

### 要改的文件

| 文件 | 改什么 |
|---|---|
| `profile.md` | 填你的学科、目标、基础 |
| `.pi/sources/` | 删掉法学源卡，建你的学科源卡（每本书/每门课一张） |
| `.pi/skills/teach-law/SKILL.md` | 把"不许编法条"改成你学科的纪律（如经管版：数字/公式/年份以课件为准） |
| `.pi/APPEND_SYSTEM.md` | 把法学特定规则改成你学科的 |
| `学习路线.md` | 写你的学习路线和教案 |

### 不用改的文件

| 文件 | 原因 |
|---|---|
| `.pi/extensions/` | 菜单、判分、笔记镜像 — 学科无关 |
| `tools/` | PDF/PPTX 转换、OCR — 学科无关 |
| `.pi/skills/practice-law/SKILL.md` | 判分逻辑学科无关，换题库就行 |

### 建议的初始化流程

1. 打开文件夹，对 AI 说：「我要学【你的学科】，目标是【考研/期末/自学】。帮我看看要改哪些文件。」
2. AI 会逐个文件帮你改
3. 把第一份课件转成逐页文本
4. 开始第一节课
